## 基本信息

| 项 | 内容 |
|----|------|
| **名称** | Toy Dairy（玩偶生命手帐） |
| **一句话** | 让玩偶拥有身份与视角的 AI 生命手帐 |
| **比赛主题** | **Reverse** — 视角与主客体反转 |
| **Slogan** | Reverse the gaze. 从物品到陪伴。 |
| **形态** | 移动端优先 Web App（桌面居中约 390px） |
| **生产地址** | https://toydiary.pages.dev |
| **路演域（若绑）** | https://toydiary.outwardly.dpdns.org |
| **目标用户** | 喜欢收藏 / 携带玩偶旅行、拍照，并希望用玩偶记录生活与情绪的年轻人 |

### Reverse 如何落地

| 层 | 产品表现 |
|----|----------|
| 视角反转 | 同一瞬间并列「我的视角」与「玩偶视角」第一人称日记 |
| 主客体反转 | 身份卡：名称、生日、性格、独白 — 玩偶从道具变角色 |
| 关系反转 | 成长轨迹 / 纪念日沉淀**双向**记忆 |

### 产品原则

1. **玩偶是主角，不是滤镜**  
2. **双视角** — `userNote` 与 `aiDiary` 并列，不混成一段 AI 文案  
3. **手帐感 > 功能堆叠**  
4. **演示优先** — 主路径 3 分钟能讲完  

---

## 核心体验链路

```
身份卡（档案 Home）
  → 上传旅行/日常照片或文字
  → 生成主人视角 + 玩偶视角
  → 成长时间轴 / 旅行地图
  → 对话陪伴
  → 正数日与分享卡片
```

---

## 核心对象（语义）

**Toy（玩偶）**  
`name, birthDate, birthPlace, role, traits[]` → 派生 `zodiac, bio, monologue, avatarUrl?`

**Entry（事件/日志）**  

| 字段 | 含义 |
|------|------|
| `userNote` | **我的视角** |
| `aiDiary` | **玩偶视角**（第一人称） |
| `place` | 结构化地点（地图、城市统计） |

类型：`travel | daily | memorial | text | heart`（`heart` 保存时常映射为 `daily`）

---

## 主路径演示脚本（≤3 分钟）

```
打开 App（登录或随便看看）
  → 档案：介绍当前玩偶（如 Luna）
  → ＋：拍/选图或写一句 → AI 生成玩偶日记
  → 保存
  → 成长：时间轴点进刚写的那条
  → 详情：朗读双视角；可选分享卡片
  →（可选）地图 / 对话 / 正数日
  → 收束：「玩偶有了自己的记忆」
```

---

## MVP 边界（摘要）

**P0 必须能演示：** 建玩偶 · 记一条 · 双视角详情 · 切换玩偶 · 演示数据可重置  

**P1 有则展示：** 回忆展厅 / 正数日 / 地图 / AI 对话 / 主题 / OCR / 备份分享  

**Out of scope：** 硬件硬依赖 · 真账号云同步/支付 · 完整社交 · 桌面打包 · 系统推送  

详见 [PRD §5](../PRD.md)。
