# Toy Dairy · 简略 PRD（演示冲刺版）

> 参考：[`readme.md`](../readme.md) 产品原文 · [`plan.md`](../plan.md) 60h 协作计划  
> 定位：**时间不够时的对齐文档**——只答「做什么 / 不做什么 / 演示讲什么」。  
> 状态：前端 Web 已可演示；数据以浏览器 Mock 为主；真后端/R2 为加分项。

---

## 1. 一句话

**让玩偶拥有身份与视角的 AI 生命手帐**：用户创建玩偶人格，用照片/文字记录相处瞬间，系统以「主人视角 + 玩偶第一视角」双叙事沉淀成长轨迹。

---

## 2. 问题与用户

| 项 | 说明 |
|----|------|
| **痛点** | 玩偶只是照片里的「物品」，没有身份、独白与可回看的共同故事 |
| **用户** | 带玩偶旅行/拍照、重视情绪陪伴与手帐感的年轻人 |
| **核心价值** | 身份卡（谁）→ 记录（发生了什么）→ 双视角叙事（我怎么说 / 它怎么说）→ 成长时间轴（我们走过哪里） |

---

## 3. 产品原则（少而清晰）

1. **玩偶是主角，不是滤镜** —— 每条记录优先可读「玩偶视角」。  
2. **双视角** —— 主人叙述（`userNote`）与玩偶日记（`aiDiary`）并列，不混成一段。  
3. **手帐感 > 功能堆叠** —— UI 软、可滑、可点开回味；宁缺社交完整度。  
4. **演示优先** —— 主路径 3 分钟能讲完；假数据也要像真故事。

| Tab | 路由 | 用户能干什么（现状） |

## 5. MVP 范围（冲刺只保这些）

### 5.1 必须能演示（P0）

| 故事 | 验收标准 |
|------|----------|
| **建玩偶** | 填名称/生日/出生地/身份/性格 → 得到星座+简介+独白 → 身份卡可看 |
| **记一条** | 选玩偶 + 图或文字 + 日期/地点 → 保存后出现在成长/档案相关列表 |
| **双视角详情** | 从成长点进事件：上块「我的视角·用户昵称」= `userNote`；下块「玩偶视角·玩偶名」= `aiDiary`；可「重写」刷新玩偶文案 |
| **切换玩偶** | 成长/档案能切换当前玩偶，列表跟切换走 |
| **演示数据** | 种子文案够长、够有画面；「重置演示数据」可恢复 |

### 5.2 已有则展示，不做深挖（P1）

- 回忆展厅 / 纪念天数卡片（能点开讲故事即可，不抠动效）  
- 社区 feed / 来信（讲「未来玩偶社交」即可，不修全量边界）  
- 主题配色、手帐视觉 polish  
- 相机 OCR 填描述（有则演示，无则跳过）

### 5.3 明确砍掉 / 下轮（Out of scope）

- 硬件激活端、真 AI 对话陪伴  
- 完整旅行地图（真实 GIS）  
- 账号体系 / 支付会员  
- 插画生成、拍立得分享导出到社交平台  
- 桌面客户端打包  

**真后端（可选加分，不阻塞演示）**

| 项 | 说明 |
|----|------|
| API | 对齐 plan：`/toys`、`/entries`、generate-profile / regenerate |
| 存储 | D1/Postgres 存元数据；R2 存图（资源已可预建） |
| AI | 服务端按性格生成 `aiDiary`；前端只展示 |
| 未就绪时 | 保持 `USE_MOCK = true` + localStorage，**演示照常** |

## 6. 核心对象（契约摘要）

**Toy（玩偶）**  
`name, birthDate, birthPlace, role, traits[]` → 派生 `zodiac, bio, monologue, avatarUrl?`

**Entry（事件/日志）**  
`type(travel|daily|memorial|text), date, location?, title?, userNote?, mood?, imageUrl?, aiDiary?`

| 字段 | 产品含义 |
|------|----------|
| `userNote` | **我的视角**（主人怎么叙述这件事） |
| `aiDiary` | **玩偶的视角**（第一人称 AI/预置日记） |

双视角 UI 规则（实现约定）：

1. 我的视角：优先 `userNote` → 否则 `title` → 否则按地点/玩偶生成一句兜底  
2. 玩偶视角：优先 `aiDiary` → 否则按性格模板兜底；「重写」只动玩偶侧

## 7. 主路径用户流程（演示脚本）

```
打开 App
  → 档案：介绍当前玩偶（Luna）
  → ＋：拍/选一张图或写一句
  → 保存：提示「日志已生成」
  → 成长：时间轴点进刚写的那条
  → 详情：朗读「我的视角」+「玩偶视角」
  →（可选）切换豆豆 / 看身份卡 / 点一下社区
  → 结束：强调「玩偶有了自己的记忆」
```

时长目标：**≤ 3 分钟**。

## 8. 成功标准（冲刺结束）

| 维度 | 达标 |
|------|------|
| **故事** | 评委/路人能复述：身份卡 + 双视角日记 + 成长轴 |
| **稳定** | 刷新不白屏；重置演示后主路径仍通 |
| **观感** | 手机宽手帐风；加载不是简陋 emoji（可用 SVG 小熊） |
| **范围** | 没人再临时加「完整地图/登录/支付」进本轮 |

## 9. 剩余时间怎么排（建议）

| 优先级 | 事项 | 说明 |
|--------|------|------|
| ① | 锁演示脚本 + 种子文案 | 每条 P0 记录都有完整 userNote / aiDiary |
| ② | 双视角详情打磨 | 从成长进入返回成长；昵称读「我的」页 |
| ③ | 主路径 bug | 切玩偶串数据、空状态、重置后列表 |
| ④ | 录屏 / 检查表 | 弱网、清缓存、第二次打开 |
| ⑤ | 真 API/R2 | **仅当 P0 全绿且有人手** |

**不做的决策默认：砍功能，不砍演示完整度。**
