# Toy Dairy · 产品介绍

## 一句话

**Toy Dairy（玩偶生命手帐）** 是让玩偶拥有身份与视角的 AI 生命手帐——把「人看玩偶」反转成「玩偶看世界」。

## 我们在解决什么

越来越多年轻人会带着玩偶旅行、拍照，把玩偶当作情绪与记忆的载体。但在相册里，玩偶往往只是「物品」：没有名字以外的身份，没有独白，也没有一段可以回看的共同故事。

Toy Dairy 把陪伴物从被记录的**客体**，变成共同生活的**叙事主体**。

## 主题：Reverse

| Reverse 层 | 产品落地 |
|------------|----------|
| **视角反转** | 同一瞬间同时呈现「我的视角」与「玩偶视角」第一人称日记 |
| **主客体反转** | 身份卡赋予名称、生日、性格、独白——玩偶从道具变成角色 |
| **关系反转** | 成长轨迹与正数日沉淀双向记忆，而不只是人单方面收藏 |

**Slogan**

- 英文：*Through toy eyes, your world rewinds.* / *Reverse the gaze.*
- 中文：换个视角，用玩偶记录生活与情绪。 / 从物品到陪伴。

## 为谁而做

喜欢**收藏 / 携带玩偶旅行、拍照**，并希望用玩偶记录生活与情绪的年轻人。

## 核心体验链路

```
身份卡 → 上传旅行/日常照片或文字 → 主人视角 + 玩偶视角
  → 成长时间轴 / 旅行地图 → 对话陪伴 → 正数日与分享卡片
```

1. **档案** — 当前玩偶身份卡、陪伴纪念、统计入口  
2. **记一笔** — 相册 / 拍照 / 纯文字，生成双视角记录  
3. **成长** — 时间轴与旅行地图，回看一起走过的路  
4. **对话** — 与玩偶闲聊，延续陪伴感  
5. **正数日 / 我的** — Days Matter 风格大数字、主题配色、备份与分享  

## 产品原则

1. **玩偶是主角，不是滤镜** —— 每条记录优先可读「玩偶视角」  
2. **双视角并列** —— 主人叙述（`userNote`）与玩偶日记（`aiDiary`）分开呈现，不混成一段 AI 文案  
3. **手帐感 > 功能堆叠** —— 软萌 scrapbook 视觉，可滑、可点开回味  
4. **演示优先** —— 主路径约 3 分钟能讲完；假数据也要像真故事  

## 差异化

| 常见做法 | Toy Dairy |
|----------|-----------|
| 给照片加可爱滤镜 / 贴纸 | 玩偶有独立人格与第一人称叙事 |
| 单一 AI 总结文案 | **我的视角** 与 **玩偶视角** 并列 |
| 只做收藏清单 | 身份 → 记录 → 成长 → 对话 → 纪念日式正数日 |

## 产品形态与技术摘要

| 项 | 内容 |
|----|------|
| 形态 | 移动端优先 Web App（桌面居中约 390px 手机框） |
| 视觉 | 软萌手帐 / scrapbook kawaii；多套主题（抹茶绿 · 暖杏 · 雾蓝 · 蜜桃 · 薰衣） |
| 技术 | React · TypeScript · Vite · Tailwind · Cloudflare Pages Functions |
| 数据 | 演示 CRUD 默认 localStorage；AI 日记 / 对话可走服务端 |
| 演示 | https://toydiary.pages.dev |

## 结语

Toy Dairy 不是「再多一个 AI 写文案的工具」，而是完成一次**谁在讲故事**的反转——从「我记录玩偶」到「玩偶与我共同记录生活」。
