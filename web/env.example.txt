# / 地图反查会全部静默失效。

# 本文件是唯一能提交的环境变量载体（.env 和 .env.* 同时被根 .gitignore 与

# —— 注意 .env.ios 本身不要提交：

# VITE_AI_ANALYZE_ENDPOINT=https://toydiary.pages.dev/api/analyze-entry
